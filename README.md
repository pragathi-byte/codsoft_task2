# Quiz App

## Description
Quiz App is an Android application that allows users to test their knowledge through multiple-choice questions. It provides an interactive and engaging quiz experience with instant score calculation.

## Features
- User-Friendly Interface
- Multiple-Choice Questions
- Score Calculation
- Result Screen
- Easy Navigation

## Technologies Used
- Android Studio
- Java/Kotlin
- XML
- Firebase (Optional)
- Figma

## Installation
1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Gradle and run the application.

```bash
git clone https://github.com/your-username/QuizApp.git
```
